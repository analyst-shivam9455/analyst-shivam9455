## 📂 Featured Projects

### 🛒 [E-Commerce Revenue & Logistics Analysis](https://github.com/analyst-shivam9455/E-Commerce-Revenue-Customer-Behavior-Logistics-Cost-Analysis)
- Analyzed 100K+ orders and found **12–15% were loss-making** (logistics cost > product value)
- Discovered top 20% of customers drive **65% of total revenue** using Pareto analysis
- Built a Power BI dashboard reducing analysis time by 25%
- **Tools:** SQL, Power BI

### 📦 [Supply Chain Analytics & Inventory Optimization](https://github.com/analyst-shivam9455/Supply-Chain-Analytics-And-inventory-Optimization)
- Identified **18% slow-moving/overstocked inventory** contributing to high holding costs
- Found **22% of orders were delayed**, signaling logistics bottlenecks
- Built a 5-page Power BI dashboard covering inventory, fulfillment, and profit analysis
- **Tools:** SQL (MySQL), Power BI, DAX

### ✅ [Olist Data Validation Project](https://github.com/analyst-shivam9455/Olist-Data-Validation-Project)
- Ran **100+ data quality checks** across multiple relational tables
- Flagged 200K+ issues across completeness, consistency, validity, and uniqueness
- Built a Power BI dashboard to track data quality scores for stakeholders
- **Tools:** Python, Power BI
